# Explainable Dual-Feature Fusion Framework for Neonatal Sleep Apnea Detection

## Overview
This project proposes a transformer-based deep learning framework for early detection of neonatal sleep apnea using overnight physiological time-series data.

## Features
- ECG and respiratory signal analysis
- Dual-feature fusion using TCN + Bi-GRU
- Transformer-based classification
- SHAP Explainable AI integration
- High detection accuracy

## Technologies Used
- Python
- TensorFlow / Keras
- Deep Learning
- Transformers
- SHAP
- Jupyter Notebook

## Results
- Accuracy: 98.63%
- Precision: 98.35%
- Sensitivity: 98.47%
- Specificity: 98.56%
